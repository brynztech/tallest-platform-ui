# Quick Task: Recruiter role-assignment write path

## Goal

An Admin or Account Manager can assign/unassign a recruiter to a requisition from
the requisition detail page; the recruiter's My Roles view reflects it. Closes the
gap where `ops_assignments` existed with only a read endpoint and no UI.

## Tasks

### Task 1 — Backend write endpoints (../talent-platform, branch backend-dev)
- `ops/schemas/assignments.py`: `CreateAssignmentRequest`, `RequisitionAssigneesResponse`
- `ops/services/assignments.py`: `create_assignment` (404 on missing req, idempotent
  on the existing unique constraint), `delete_assignment` (idempotent),
  `get_requisition_assignee_ids`
- `ops/router.py`: `POST /ops/assignments` (201), `DELETE /ops/assignments` (204,
  query params), `GET /ops/requisitions/{req_id}/assignees` (200)
- `tests/ops/test_assignments.py`: lifecycle test (assign → assignees + user view →
  duplicate idempotent → unassign) + 404 test
- `docs/recruiter-assignments.md`: endpoint doc

### Task 2 — Console UI (this repo, branch frontend-dev)
- `app/(shell)/_lib/assignments.ts`: `forRequisition` query key, fetch/assign/unassign
  helpers, pure `assignableRecruiters()` helper
- New `app/(shell)/ops/requisitions/[id]/_components/assigned-recruiters-card.tsx`:
  read-only list for viewers; add/remove gated by `requisition.manage` (AM + Admin)
- Wire into requisition detail page
- `packages/mocks/src/handlers/assignments.ts`: POST/DELETE + assignees GET handlers
- `apps/console/src/__tests__/assignments.test.ts` (.ts — JSX Vitest bug workaround)
- `docs/recruiter-role-assignment.md`: feature doc

## Done condition

Backend pytest passes; console vitest passes; AM/Admin can add/remove a recruiter
on a requisition; recruiter's My Roles query is invalidated; docs in both repos.
