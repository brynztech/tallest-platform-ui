## Deviations from Plan

### Minor: fs-walk instead of execSync for transition-all guard

**Found during:** Task 2 implementation

**Issue:** The plan offered execSync as the primary implementation with a fs-read fallback. The plan note said "if the grep-based test proves flaky in the runner environment, the executor may replace the execSync guard with a per-file fs read loop." Given that vitest runs in a sandboxed environment and execSync shell commands can be fragile in CI, the fs-based walk was used directly.

**Fix:** Replaced `execSync("grep -rl 'transition-all' ...")` with a `function walk(dir)` that recursively reads all `.tsx` files via `fs.readdirSync` and checks content directly. Same behaviour: zero files matching `transition-all` must be found.
