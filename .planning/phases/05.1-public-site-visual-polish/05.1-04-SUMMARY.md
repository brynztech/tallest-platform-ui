## What Was Built

### Task 1: Profile Edit Focus Ring + Site-Nav Explicit Transition

**Profile edit skill remove button (POL-06):**

The skill `×` buttons in `apps/web/app/profile/edit/page.tsx` had no focus-visible styling — keyboard users got no visual confirmation of focus. Added the standard accent ring pattern:

- Before: `className="ml-1 text-muted-foreground hover:text-foreground"`
- After: `className="ml-1 rounded-sm text-muted-foreground hover:text-foreground focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-1"`

The `rounded-sm` ensures the ring follows the button shape. `ring-ring` tracks the global `--color-ring: oklch(0.55 0.15 35)` token set in Plan 01 — no hardcoded colour.

**Site nav link transitions (POL-06):**

Both nav links in `apps/web/app/_components/site-nav.tsx` needed explicit motion duration:

- Jobs link: `'text-sm transition-colors'` → `'text-sm transition-colors duration-150 ease-out'`
- Dashboard link: had NO transition at all; added `transition-colors duration-150 ease-out` to match the Jobs link pattern

Both changes bring the site-nav into alignment with the `duration-150 ease-out` motion idiom established across the phase.
