## Security Domain

Phase 5.1 is CSS-only changes (Tailwind class updates, token overrides, one new UI component for the resume dropzone visual states). No new API endpoints, no authentication changes, no user input processing changes. ASVS categories do not introduce new threat surface.

The dropzone redesign adds `onDrop` / `onDragOver` handlers — these call `e.dataTransfer.files[0]` and set local state only. No server-side processing in these handlers. No new XSS surface. No security enforcement action required.
