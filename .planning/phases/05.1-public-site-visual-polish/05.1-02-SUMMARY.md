## What Was Built

### Task 1: Hero, Job Card, Filter Bar

**hero-section.tsx:** Removed the forbidden `style={{ paddingTop: '120px' }}` inline style. Replaced with `pt-28 md:pt-[120px]` Tailwind classes. The `font-light` editorial headline class appears exactly once (landing.test.tsx invariant preserved). Button's `variant="default"` auto-maps to the warm amber/terracotta `bg-primary` from Plan 01 tokens — no className change needed.

**job-card.tsx:** Upgraded the Link+Card hover pattern from a flat `hover:bg-muted` colour swap to a crafted lift:
- Link: added `group` class and `tabIndex={isLocked ? -1 : undefined}`
- Card: replaced single `transition-colors hover:bg-muted` string with 4 explicit strings:
  - `cursor-pointer p-4`
  - `transition-[color,box-shadow,transform] duration-150 ease-out` (bracketed — transition-shadow is invalid in Tailwind v4)
  - `hover:bg-muted/50 hover:shadow-md hover:-translate-y-px`
  - `group-focus-visible:outline-none group-focus-visible:ring-2 group-focus-visible:ring-ring`

**filter-bar.tsx:** Added accent focus rings (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-1 rounded-sm`) to all 4 raw `<button>` elements:
- "Clear all" button
- 3 pill x remove buttons (role_type, seniority, remote)

### Task 2: Locked-Jobs Overlay Redesign

Fully rewrote `locked-jobs-overlay.tsx` from a hard-bordered shadowed card to a tasteful gradient fade:
- Position: `top-1/4` floating mid-grid to `absolute inset-x-0 bottom-0` bottom-anchored
- Removed the inner `rounded-xl border border-border bg-background p-6 shadow-lg` div
- Added `bg-gradient-to-t from-background via-background/90 to-transparent` on the outer container
- Heading: `h3 text-xl` to `p text-base font-normal` (less aggressive)
- Button: `w-full` removed, `size="sm"` added (non-aggressive CTA per locked decision)
- The `from-background` gradient reads the warm `oklch(0.99 0.003 30)` token set by Plan 01 in `:root` — gradient fades to the exact same warm near-white as the page background
