**Source:** `packages/ui/src/components/ui/input.tsx` lines 11–12, `packages/ui/src/components/ui/button.tsx` line 8

**Raw `<button>` elements with NO focus ring (must add):**

### `apps/web/app/onboarding/_components/resume-dropzone.tsx` (NEW FILE)

**No existing analog.** This is extracted from the plain `<label>` in `onboarding/1/page.tsx` lines 103–115.

**Pattern source:** RESEARCH.md Surface 5 code example. HTML5 drag API + `useState(isDragOver)` — no react-dropzone dependency.

**Props interface:**
```tsx
interface ResumeDropzoneProps {
  file: File | null
  status: 'idle' | 'uploading' | 'processing' | 'failed'
  disabled?: boolean
  onChange: (file: File | null) => void
}
```

**Visual state class map:**
```tsx
// idle, no file:
'border-border/70 bg-card hover:bg-muted/50 hover:border-border'

// drag-over:
'border-primary bg-primary/5 ring-2 ring-primary/30'

// file selected (idle, not yet submitted):
'border-primary/40 bg-primary/5'

// uploading or processing:
'border-border/50 bg-muted/30'

// failed:
'border-destructive/50 bg-destructive/5'
```

**Drag events required (pitfall — must call `preventDefault` on `onDragOver`):**
```tsx
onDragEnter={() => setIsDragOver(true)}
onDragOver={e => e.preventDefault()}   // REQUIRED — browser won't fire onDrop without this
onDragLeave={() => setIsDragOver(false)}
onDrop={e => {
  e.preventDefault()
  setIsDragOver(false)
  const dropped = e.dataTransfer.files[0]
  if (dropped) onChange(dropped)
}}
```

**Icon:** `UploadCloud` from `lucide-react`, `h-8 w-8`. Colour: `text-muted-foreground` idle, `text-primary` on drag-over and file-selected.

**Imports:**
```tsx
'use client'

import { cn } from '@brynzit/ui/lib/utils'
```
