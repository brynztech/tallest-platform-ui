**One confirmed gap (WARNING severity):**

**Filter-bar location and skills pill remove buttons missing focus rings (POL-06, ROADMAP SC#6)**

The filter-bar has 6 interactive raw `<button>` elements but only 4 have `focus-visible:ring-ring`. The `location` and `skills` pill remove buttons at lines 140-144 and 148-152 have only hover styling with no focus-visible treatment. This violates the plan's original acceptance criterion ("6 focus rings") and the ROADMAP SC#6 requirement for focus rings "consistent across all inputs."

The SUMMARY acknowledges this as a deviation (Plan 02 changed the button count from the expected 5 pills to the 3-pill worktree version), adjusted the test assertion from `.toBe(6)` to `.toBeGreaterThanOrEqual(4)`, and considered the work complete with 4/6 buttons covered. However the worktree actually has all 5 filter types (role_type, seniority, location, skills, remote) visible in the file — the location and skills pills DO exist and are conditionally rendered. Their remove buttons simply had focus rings omitted during the fix.

**Fix required:** Add `rounded-sm focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-1` to the location pill remove button (line ~142) and the skills pill remove button (line ~150) in `apps/web/app/jobs/_components/filter-bar.tsx`.
