> Visual and interaction contract for the BD rep workflow in `apps/console`.

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (new-york style) |
| Preset | new-york, cssVariables: true, baseColor: neutral |

All additions use `npx shadcn@latest add <component> --cwd=packages/ui`.

## Spacing Scale

Multiples of 4px only. Declared values map to Tailwind v4 utility classes (`p-1` = 4px, `p-2` = 8px, etc.).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, badge internal padding, spinner badge offset |
| sm | 8px | Compact row padding, button gap, card action cluster gap |
| md | 16px | Card internal padding (horizontal), form field spacing |
| lg | 24px | Card vertical padding, slide-over internal section gap |
| xl | 32px | Lead queue column gap, slide-over top padding |
| 2xl | 48px | Sidebar section gap (BD vs stub sections) |
| 3xl | 64px | Page-level top padding on queue layout |

**Exceptions:**
- Touch/keyboard targets (A/R/S card buttons): minimum 32px height (h-8) — smaller than default button (h-9) to maintain queue density; meets 32px minimum for pointer targets.
- Sidebar nav item height: 36px — aligns with Linear/Attio dense nav feel.
- Pending-overlay spinner badge: 20px diameter, positioned -4px from card top-right corner.
- Keyboard shortcut overlay rows: 32px row height for scannability.

**Source:** packages/ui/src/styles/globals.css spacing aliases (xs=0.25rem, sm=0.5rem, md=1rem, lg=1.5rem, xl=2rem); console density overrides stated in CONTEXT.md specifics.

## Typography

Font: Geist, sans-serif. All sizes in rem mapped to px at 16px root.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (0.875rem) | 400 (regular) | 1.5 | Card body text, slide-over prose, form labels, table cells, sidebar nav labels |
| Label / Meta | 12px (0.75rem) | 400 (regular) | 1.4 | Muted metadata (domain, contact title, open roles count), badge text, sidebar badge counts |
| Subheading | 16px (1rem) | 600 (semibold) | 1.4 | Company name on card (primary scannable label), slide-over section headings |
| Heading | 20px (1.25rem) | 600 (semibold) | 1.2 | Slide-over company name header, empty state heading, shortcut overlay title |

**Weights used:** 400 (regular) and 600 (semibold) only. No 500/700 in this phase.

**Notes:**
- Suggested angle text on card: 14px/400, line-clamp-2, muted-foreground color.
- ICP score badge uses 12px/600 — the only label-size semibold exception, justified by its role as primary decision signal.
- Sidebar nav labels: 14px/400 (Body role) — use `text-sm` Tailwind class, consistent with all other body-size text.

**Source:** apps/console dark-mode-first convention; CONTEXT.md "Linear/Attio feel — dense, keyboard-first, no wasted vertical space."

## Color

Console is **dark-mode-first**. All values from `apps/console/app/globals.css` `:root` overrides.

| Role | OKLCH Value | Hex Approx | Usage |
|------|-------------|------------|-------|
| Dominant (60%) | oklch(0.145 0 0) | #1a1a1a | Page background (--background) |
| Secondary (30%) | oklch(0.205 0 0) | #282828 | Card surfaces (--card), popover, sheet |
| Tertiary surface | oklch(0.185 0 0) | #222222 | Sidebar (--sidebar) |
| Border / Muted surface | oklch(0.269 0 0) | #363636 | Card borders (--border), dividers, muted backgrounds |
| Accent / Brand (10%) | oklch(0.546 0.215 261.3) | ~#3B7EF6 | Reserved list below (--primary / --color-brand) |
| Destructive | oklch(0.577 0.245 27.325) | ~#E5534B | Reject button, reject popover active state, error badges |
| Foreground | oklch(0.985 0 0) | ~#F9F9F9 | Primary text (--foreground) |
| Muted foreground | oklch(0.708 0 0) | ~#A8A8A8 | Secondary text, metadata, placeholder (--muted-foreground) |

**Accent (brand blue) reserved for:**
1. Focused card keyboard highlight ring
2. Primary approve button (`variant="default"` = bg-primary)
3. Sidebar active route indicator (left border or bg tint)
4. Sidebar nav badge counts (text-primary)
5. ICP score badge when score ≥ 80 (high-signal lead)
6. Link text in slide-over (company URL, contact LinkedIn)

**ICP score color ranges (semantic, not brand):**
- Score ≥ 80: `bg-primary text-primary-foreground` (brand blue — strong buy signal)
- Score 60–79: custom `bg-[oklch(0.769_0.188_85.87)]` (--chart-2 amber) with dark text — "consider"
- Score < 60: `bg-muted text-muted-foreground` (neutral grey) — "weak"

**Status badge colors:**
- "Snoozed": `variant="outline"` with amber border (`border-[oklch(0.769_0.188_85.87)]`)
- "Sequence ready": `variant="secondary"` (muted surface, subtle)
- "Urgent reply": `variant="destructive"` but with amber — custom `bg-[oklch(0.769_0.188_85.87)/20] text-[oklch(0.769_0.188_85.87)] border-[oklch(0.769_0.188_85.87)/40]`

**Pending-overlay state:** card `opacity-50` + pointer-events-none during bulk processing. Spinner badge: `bg-muted border-border` with `text-muted-foreground` spinner icon.

**Error revert badge:** `variant="destructive"` small badge positioned top-right of card.

**Source:** apps/console/app/globals.css; packages/ui/src/styles/globals.css chart tokens.

### Undo Toast (CUX-02)

Using existing Sonner `<Toaster>` component. Call pattern:

```
toast("Approved", {
  description: "Acme Corp moved out of queue.",
  action: { label: "Undo", onClick: handleUndo },
  duration: 5000,
})
```

- Position: `bottom-right`
- Toast width: default Sonner width (~356px)
- Action button: Sonner's built-in action slot (underline, text-primary on hover)
- For reject: `toast("Rejected — Not a fit", { action: { label: "Undo", ... } })`
- For snooze: `toast("Snoozed until Jan 20", { action: { label: "Undo", ... } })`

## Interaction Contracts

### Keyboard Navigation (CUX-03)

- **Activation scope:** Queue has a `data-queue-focused` attribute. Shortcuts fire on `keydown` when `document.activeElement` is inside the queue container AND no text input or Sheet/Dialog is open.
- **J:** Move focus to next card (wraps at bottom of loaded set).
- **K:** Move focus to previous card (wraps at top).
- **A:** Trigger Approve on focused card (same as clicking Approve button).
- **R:** Open Reject popover on focused card. Arrow keys navigate reason list. Enter selects.
- **S:** Open Snooze popover on focused card. Arrow keys navigate presets. Enter selects.
- **Enter:** Open slide-over for focused card.
- **Escape:** Close slide-over or popover; return focus to triggering card.
- **?:** Toggle keyboard shortcut Dialog.
- **Space:** Toggle bulk-select checkbox on focused card.

### Optimistic Update + Undo (CUX-02)

1. User clicks Approve / Reject / Snooze on card.
2. Card immediately plays exit animation (`slide-out-to-right-4 fade-out duration-200`).
3. Sonner toast appears (bottom-right) with "Undo" action, duration 5000ms.
4. API call fires after 300ms delay (allows undo before network).
5. If Undo clicked before API call fires: cancel API call, replay entrance animation (`slide-in-from-right-4 fade-in duration-200`), dismiss toast.
6. If Undo clicked after API call fires: fire compensating API call (un-approve / re-queue), replay entrance animation.
7. If API call fails (no undo): toast upgrades to error toast "Action failed — [Company] restored." Card reappears.

### Bulk Action Sequence (D-09, D-10)

1. User selects ≥1 cards via checkbox or Shift+click.
2. Bulk toolbar appears in sticky header row.
3. User triggers bulk action (Approve / Reject with shared reason / Snooze).
4. All selected cards enter pending state (opacity-50, spinner badge).
5. API calls fire (POST /bd/leads/bulk-action).
6. On settlement per card: success → exit animation; failure → error badge, full opacity restored.
7. After all settle: cursor resets to page 1, queue refetches.
8. Single undo toast for bulk action: "Approved 12 leads. Undo" (5-second window).

### Slide-over Focus Lifecycle (CUX-01)

1. Card click (body area, excluding action buttons and checkbox) → Sheet opens from right.
2. `onOpenAutoFocus`: focus moves to SheetContent container (focusTrap active).
3. Tab cycles through slide-over interactive elements only.
4. Escape or close button → Sheet closes → `onCloseAutoFocus`: focus returns to the originating card element.
5. Queue in background: `aria-hidden="false"` but visually dimmed via overlay.
